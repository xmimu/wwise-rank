## 1. 简介

Wwise Rank 是一款运行在 Windows 桌面的悬浮窗小工具，专为 Wwise 音频工程师设计。它通过 **WAAPI（Wwise Authoring API）** 监听你在 Wwise 中的实际操作，并以积分形式量化工作投入，让你能够直观感知当前的操作节奏与累计工作量。

**适用场景：**

- 个人工作效率追踪
- 团队工作量可视化
- 学习过程中的操作频次统计

## 2. 安装与启动

### 2.1 直接使用（推荐）

从发布页面下载安装包（`.msi`），双击安装后启动 `wwise-rank.exe` 即可。

应用以透明悬浮窗形式出现在屏幕上，默认置顶显示。

### 2.2 从源码构建

**环境要求：**

| 工具 | 最低版本 |
|------|----------|
| Rust | 1.70+ |
| Node.js | 18+ |
| pnpm | 8+ |

**步骤：**

```bash
# 克隆仓库
git clone <仓库地址>
cd wwise-rank

# 安装前端依赖
pnpm install

# 开发模式（热重载）
pnpm tauri dev

# 构建发布包
pnpm tauri build
```

### 2.3 启动前准备

启动 Wwise Rank 前，请确保：

1. Wwise 已打开并加载了工程
2. Wwise 的 **WAAPI（本地 WebSocket 服务）** 已启用

启用 WAAPI 的方法：Wwise 菜单 → **Project** → **User Preferences** → 勾选 **Enable WAAPI**，端口保持默认（`8080`）。

## 3. 界面说明

### 3.1 主视图（320×200）

```
┌─────────────────────────────────────┐
│ ● WWISE · RANK              [↓] [×] │  ← 标题栏（拖拽区）
├─────────────────────────────────────┤
│  [  RANK  ] │ [ SCORE  ] │ [ STATE ]│  ← 三栏读数
│   12,480    │    360     │ CONNECTED│
├─────────────────────────────────────┤
│ ACT [██████████████░░░░░░░░░░] 14   │  ← VU 电平条
├─────────────────────────────────────┤
│       [ ANALYZE ]  [ SETTINGS ]     │  ← 操作按钮
└─────────────────────────────────────┘
```

### 3.2 标题栏

| 元素 | 功能 |
|------|------|
| `●` 圆点指示灯 | 亮琥珀色 = 窗口已置顶；暗灰色 = 未置顶 |
| `WWISE · RANK` 文字区域 | 按住拖拽可移动窗口 |
| `↓` 图标按钮 | 切换窗口置顶 / 取消置顶（亮起时 = 已置顶） |
| `×` 关闭按钮 | 关闭应用 |

**窗口吸附：** 拖拽窗口靠近屏幕边缘 80px 以内时，会自动吸附到边缘并有光晕闪光反馈。

### 3.3 三栏读数

| 栏位 | 标签 | 说明 |
|------|------|------|
| 左 | **RANK** | 自安装起累计的总排名分，跨会话持久化，不会因重启清零 |
| 中 | **SCORE** | 本次启动后获得的分数，重启应用后归零 |
| 右 | **STATE** | 当前连接状态（见下表） |

分数变化时，数值会有平滑动画过渡（ease-out cubic）并伴随发光闪烁提示。

**连接状态（STATE）：**

| 状态 | 颜色 | 说明 |
|------|------|------|
| IDLE | 灰色 | 无可用端口，等待重试 |
| SCANNING | 琥珀色（闪烁）+ 扫描线动效 | 正在尝试连接 Wwise |
| CONNECTED | 绿色（窗口边框也变绿） | 已连接，正常监听 |

### 3.4 VU 电平条

24 段横向色条，反映**近期事件触发频率**。操作越密集，亮起的段数越多；停止操作后，亮度以每 1.5 秒衰减 2 段的速率逐渐降至零。

| 段位 | 颜色 | 含义 |
|------|------|------|
| 1–16 | 琥珀绿 | 正常活跃 |
| 17–20 | 橙黄（warn） | 高频操作 |
| 21–24 | 红色（danger，脉冲动效） | 极高频操作 |

右侧数字显示当前亮起段数，无活动时显示 `–`。

### 3.5 操作按钮

| 按钮 | 功能 |
|------|------|
| **ANALYZE** | 预留功能（暂无操作） |
| **SETTINGS** | 打开设置面板（窗口扩展至 420px 高） |

## 4. 连接 Wwise

### 4.1 自动连接流程

应用启动后自动运行，无需手动操作：

1. **TCP 端口探测** — 并行扫描配置的端口范围（默认 `8080–8083`），找到监听端口
2. **WebSocket 握手** — 与 Wwise WAAPI 建立 WebSocket 连接
3. **就绪检测** — 调用 `ak.wwise.core.getInfo` 接口确认 Wwise 已完全就绪
4. **事件订阅** — 订阅所有已启用的 WAAPI Topic，开始接收操作事件

### 4.2 断线重连

连接中断后，应用按指数退避策略自动重连：

- 初始等待约 **1.5 秒**
- 每次失败后等待时间加倍
- 最长等待不超过 **30 秒**

只要 Wwise 重新可用，应用会自动恢复连接，**无需手动干预**。

### 4.3 保存设置后立即重连

在设置面板点击 **SAVE** 后，应用会立即中断当前连接并以新配置重新扫描，无需重启。

## 5. 积分系统

### 5.1 积分原则

分值依据操作的**复杂度与影响范围**设计：

- 创建、生成、结构性变更等高复杂度操作得分高（4–5 分）
- 属性调整、曲线编辑等中等操作居中（3–4 分）
- 重命名、备注、选择等低复杂度操作得分低（1–2 分）

### 5.2 默认分值与启用状态

详见 [操作计分表](操作计分表.md)。以下为简要汇总：

| 分值 | 操作类型 |
|------|----------|
| **5 分** | 创建对象、SoundBank 生成（单个/全部完成） |
| **4 分** | 导入音频、引用更改、Switch Container 指派添加 |
| **3 分** | 添加子对象、删除对象、曲线更改、属性更改、工程加载/保存、Switch Container 指派移除 |
| **2 分** | 移除子对象、重命名对象、工程关闭 |
| **1 分** | Attenuation 曲线更改、Attenuation 曲线 Link 切换、修改备注、选择变更 |

> **默认禁用的 Topic**（可在设置面板中开启）：
> - `object.propertyChanged` — 部分 Wwise 版本不支持，且触发非常频繁
> - `object.structureChanged` — 批量操作时触发频繁
> - `transport.stateChanged` — 播放预览时触发频繁

## 6. 设置面板

点击主界面的 **SETTINGS** 按钮打开设置面板（窗口高度扩展至 420px）。

### 6.1 端口范围（PORT RANGE）

输入 Wwise WAAPI 的监听端口范围：

| 格式 | 示例 | 说明 |
|------|------|------|
| 单端口 | `8080` | 只扫描该端口 |
| 端口范围 | `8080-8090` | 扫描此范围内所有端口 |

修改后点击 **SAVE** 即时生效，应用会立即用新端口重新扫描。

### 6.2 URI 订阅列表（URI SUBSCRIPTIONS）

列出所有 22 个 WAAPI Topic，每行包含：

- **复选框** — 勾选/取消该 Topic 的监听。取消后不再触发积分，也不再发起订阅
- **Topic 名称** — 显示 Topic URI 的后两段（如 `object.created`），悬停可见完整描述
- **分值输入框** — 该 Topic 触发一次所得分数（0–9999 整数）

### 6.3 重置总分（RESET TOTAL SCORE）

红色按钮，**需二次确认**：

1. 第一次点击 → 按钮变为高亮红色并显示确认提示，3 秒内未再次点击则取消
2. 第二次点击 → 立即将 RANK 总分和事件计数清零并写入磁盘

### 6.4 开机自启（AUTO START）

切换应用是否随系统登录自动启动。

### 6.5 语言切换（LANGUAGE）

切换界面语言：**中文** / **EN**（English）。偏好保存在浏览器 localStorage，跨会话持久。

### 6.6 保存 / 取消 / 恢复默认

| 按钮 | 功能 |
|------|------|
| **SAVE** | 保存所有设置并关闭面板，立即触发重连 |
| **CANCEL** | 放弃修改，关闭面板 |
| **↺** | 将草稿重置为内置默认值（不会立即保存，需再点 SAVE） |

## 7. 数据持久化

### 7.1 数据文件

| 文件 | 内容 | 位置 |
|------|------|------|
| `score.json` | 总分（`total_score`）+ 各 Topic 累计触发次数（`event_counts`） | 应用数据目录 |
| `settings.json` | 端口范围 + 每个 Topic 的启用状态与分值 | 应用数据目录 |

**Windows 路径：**

```
%APPDATA%\com.xmimu.wwise-rank\
```

（通常为 `C:\Users\<用户名>\AppData\Roaming\com.xmimu.wwise-rank\`）

### 7.2 写入策略

- **settings.json** — 每次点击 SAVE 立即写入
- **score.json** — 采用**脏标记 + 定时批量写入**策略，每隔约 3 秒检查一次，有变化才写入磁盘。若应用意外关闭，最多丢失 3 秒内的分数变化

### 7.3 重置积分

**方法一（推荐）：** 打开设置面板 → 点击 **RESET TOTAL SCORE** → 二次确认。

**方法二（手动）：**
1. 关闭 Wwise Rank
2. 找到 `score.json`，将 `total_score` 字段改为 `0`（或直接删除整个文件）
3. 重启应用

## 8. 高级配置（环境变量）

所有网络超时参数均可通过环境变量覆盖默认值，适合网络环境特殊或 Wwise 启动较慢的情况：

| 环境变量 | 默认值 | 说明 |
|----------|--------|------|
| `WWAAPI_TCP_PROBE_MS` | `300` | TCP 端口探测超时（毫秒） |
| `WWAAPI_CONNECT_SECS` | `4` | WebSocket 连接超时（秒） |
| `WWAAPI_GETINFO_SECS` | `3` | WAAPI 就绪检测超时（秒） |
| `WWAAPI_SUBSCRIBE_SECS` | `5` | 单个 Topic 订阅超时（秒） |
| `WWAAPI_DISCONNECT_SECS` | `2` | 断线检测超时（秒） |
| `WWAAPI_BACKOFF_INITIAL_MS` | `1500` | 重连初始等待（毫秒） |
| `WWAAPI_BACKOFF_MAX_MS` | `30000` | 重连最大等待（毫秒） |

**设置方式（PowerShell）：**

```powershell
$env:WWAAPI_CONNECT_SECS = "8"
.\wwise-rank.exe
```

或通过系统「环境变量」设置持久生效。

## 9. 常见问题

### Q: 应用启动后一直显示 SCANNING，无法连接

**可能原因与解决方法：**

1. Wwise 未打开 → 打开 Wwise 并加载工程
2. WAAPI 未启用 → 在 Wwise 中开启 WAAPI（参见第 2.3 节）
3. Wwise 使用了设置范围之外的端口 → 在设置面板将端口范围调整为 Wwise 实际使用的端口
4. 防火墙阻止了本地 WebSocket 连接 → 检查 Windows Defender 或其他防火墙设置，允许本地回环连接

---

### Q: 分数没有变化，但 Wwise 中有操作

**可能原因：**

1. 未处于 CONNECTED 状态 → 确认 STATE 栏显示绿色 CONNECTED
2. 触发的事件类型被禁用 → 打开设置面板，在 URI SUBSCRIPTIONS 中确认对应 Topic 已勾选
3. 触发的事件不在支持的 22 个 Topic 内 → 参考 [操作计分表](操作计分表.md)

---

### Q: 如何完全重置所有数据

删除应用数据目录下的 `score.json` 和 `settings.json`，重启应用后将重新生成默认配置，总分归零。

---

### Q: 应用窗口消失了，找不到

- 可能被移到了屏幕之外。在任务栏右键点击应用图标，选择「移动」，然后用方向键将窗口移回屏幕可见区域。
- 如果任务栏也找不到，可直接重启应用，窗口会回到默认位置。

---

### Q: 修改了设置，分数没有变化

- 确认已点击 **SAVE**（点 CANCEL 或直接关闭不会保存）
- 检查对应 Topic 的复选框是否已勾选

---

### Q: 想提高某个操作的分值，怎么做

打开设置面板 → 在 **URI SUBSCRIPTIONS** 列表中找到对应 Topic → 修改右侧数值输入框 → 点击 **SAVE**。
